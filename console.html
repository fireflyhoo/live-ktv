接入真实平台弹幕

舞台开着一个本地服务，几种方式都能把弹幕送进来：

  1. HTTP 单条
    POST http://127.0.0.1:8787/danmaku
    {"user":"昵称","text":"内容","emote":"😍"}
  2. WS
    ws://127.0.0.1:8787 直接推同结构 JSON
  3. postMessage
    postMessage({type:'danmaku',...},'*')
  4. 视频号整包（推荐抓取脚本用）
    POST http://127.0.0.1:8787/video-channel-live
    把 {type:'video_channel_live', comments:[...], viewers:[...]} 原样发过来，服务端拆包、跨批次去重、同名合并。支持跨域。

整包接口返回 {"ok":true,"accepted":N,"duplicates":M,"viewersOnStage":K}，连推同一份快照不会重复生成小人。观众榜默认也上台（只有名字不弹气泡），前三名给 VIP 名牌；不要就加 ?includeViewers=0，要调人数用 ?maxViewers=50。

推了什么、谁上台了、谁被判为重复，都直接打印在跑服务那个终端里，不用回浏览器看。

B 站可在服务端直连；抖音 / 视频号用抓取脚本转发到上面任一入口。详见 README。

舞台本身不带任何 UI，方便 OBS 直接采集。
这个控制台和舞台之间走同源广播，改什么都是即时生效。
